# Soumik Halder — Portfolio

A React + Vite portfolio presenting selected independent products, engineering experience and technical work.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Project notes

- `src/pages/Home.jsx` contains the homepage, selected projects and technical positioning.
- `src/pages/ProfessionalJourney.jsx` contains employment and education history.
- `src/pages/EngineeringLab.jsx` contains technical project notes and diagrams.
- `src/data/projects.js` stores data used by individual project case-study pages.
- `public/social-card.png` is the Open Graph / Twitter preview image (1200 × 630).
- `public/me.png` and `src/assets/me.png` are the supplied photograph used in the site identity, navigation avatar, footer and contact page. The source image is a group photograph; the interface uses a compact crop for the avatar and labels the larger image as a group photograph.

Some independent work is intentionally described without identifying its product or commercial concept.

## Visual assets

- `src/assets/hero-system.svg` is the homepage's custom systems illustration.
- `src/assets/projects/*.svg` contains original project artwork used on the selected-work cards.
- `src/assets/hero.png` is a high-resolution raster export of the hero illustration for reuse.
- `public/social-card.png` is the 1200 × 630 Open Graph / social preview image.
- `public/me.png` and `src/assets/me.png` preserve the supplied profile-photo asset. The current supplied image is a group photograph, so it is not used as an individual headshot in the hero.

The public portfolio presents the proprietary platform only as a sanitised engineering case study. Confidential product concepts are intentionally excluded.
